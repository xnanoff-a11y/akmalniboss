OUR LITTLE WORLD ♡ - START HERE

1. Extract folder ini.
2. Buka VS Code > File > Open Folder > pilih folder our_little_world.
3. Install extension "Live Server" (Ritwick Dey).
4. Right click index.html > Open with Live Server.
5. Letak gambar couple dalam folder ini dan namakan photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg.
6. Buka script.js dan tukar tarikh anniversary kepada tarikh korang (YYYY-MM-DD).
7. Edit ayat dalam index.html ikut cerita korang.

Nota: Gunakan gambar dan lagu yang korang sendiri ada hak/izin untuk guna.
